auto-work↗

github.com/weitanai/auto-work

Raycast API · React · TypeScript · OpenAI

基于 Raycast 的 AI 文本工作流扩展：选中或复制任意文本后，一键完成改写、摘要与问答， 结果直接写回剪贴板，省掉在应用之间反复切换的成本。

三个动作共用同一套入口与模式切换，只需配置自己的 OpenAI API Key 即可运行。

改写 / 摘要 / 问答 · MIT

devloop-agent-pack↗

github.com/weitanai/devloop-agent-pack

OpenClaw · Skills · Cron · 飞书 API

开箱即用的多 Agent 开发闭环：Cron 每日触发选题，飞书确认方向后生成 PRD， 再按 S / M / L / XL 分级调度 Dev 并行编码；Test 审查不通过就回流修复， Core Dev 复核后才合并主干。

七个角色分工明确（product / core-dev / dev / test / marketing / hook / research）， 知识按项目留痕到 decisions、discussions 与设计索引，升级时保留自定义人格。
